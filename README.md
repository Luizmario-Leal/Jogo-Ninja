**Jogo Ninja**

O projeto foi desenvolvido em Python utilizando a biblioteca PgZero e a classe `Rect` para detectar cliques no menu. O jogo implementa movimentação do jogador, colisões, pontuação, sistema de vidas e geração aleatória de objetos. A interface possui menu principal, controle de música, efeitos sonoros e tela de fim de jogo. A lógica é organizada nas funções `update()`, `draw()` e `on_mouse_down()`, responsáveis pela atualização do jogo, renderização dos elementos e interação com o usuário, respectivamente.
